feat(wallet-payment): DW-8 wallet + payment module

Restores the wallet and payment modules on top of the DW-1 auth
baseline. Adds full wallet management and PhonePe payment integration.

What's Added
------------
- Wallet module (backend + frontend)
  - Create wallet with alias + state
  - Balance, summary, transactions endpoints
  - Wallet pages: create, wallet, details, summary, transactions

- Payment module (backend + frontend)
  - PhonePe integration (order creation, hosted checkout)
  - Server-to-server webhook for settlement
  - Browser redirect callback handler
  - Payment pages: add-money, checkout, verify, history, details

- Config
  - backend/src/config/phonepe.js (PhonePe SDK client)

Changes
-------
- backend/src/app.js: register /api/wallet and /api/payment routes
- Full Prisma schema (Wallet, PaymentOrder models) already present from
  DW-1 baseline — no schema changes needed

Tested

- Backend starts cleanly with all three modules (auth, wallet, payment)
- Wallet creation flow works
- PhonePe payment flow works end-to-end:
  * create order -> PhonePe checkout -> callback -> webhook -> settled
- Wallet balance updates correctly after payment
- Dashboard shows wallet state
