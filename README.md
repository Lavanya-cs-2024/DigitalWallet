# DigitalWallet
A full-stack digital wallet and expense-splitting system with secure authentication, Razorpay wallet funding, transaction management, group expenses,
and multiple expense-splitting methods.

## Project Overview

The Digital Wallet system provides users with a secure platform to:

- Create and verify an account through email OTP
- Log in securely and reset forgotten passwords
- Enable Two-Factor Authentication
- Access a personalized dashboard
- Create and manage a digital wallet
- Fund the wallet through Razorpay
- View wallet balance and transaction history
- Create expense groups and add members
- Split shared expenses using multiple splitting methods
